# Старославянский переводчик и словарь

Статическое веб-приложение (Vite + чистый JS/CSS), без серверной части, LLM и платных API.
Переводит слова и предложения Старославянский ⇄ Русский, показывает словарную статью с грамматикой.

## Возможности

- Две панели с кнопкой смены направления, очисткой и копированием перевода.
- Одно слово: перевод, автодополнение, подробная словарная статья (часть речи, толкование, формы, родственные слова, греческий оригинал, этимология, пример).
- Предложение: пословный разбор. Найденные слова подсвечены (сплошная линия — точно, пунктир — приблизительно), клик по слову открывает его статью. Грамматика не учитывается: слова даются в словарной форме.
- Слова под титлом: `бг҃ъ`, `гд҇ь`, `іс҃ъ`, `чл҃вѣкъ`, `дх҃ъ`, `цр҃ь`, `ап҇лъ`, `бцⷣа` распознаются и раскрываются (`бг҃ъ → богъ`), как с титлом, так и без него.
- Нечёткий поиск: ѣ=е, ѧ/ѩ=я, ѫ=у, ѭ=ю, ѡ=о, і/ѵ=и, ѳ=ф, ѕ=з, ѱ=пс, ѯ=кс, еры отбрасываются, слоговые ръ/рь/лъ учитываются (`слъньце` ~ `солнце`). Можно искать и латиницей: `bogŭ`, `rǫka`.
- Сворачиваемая строка-клавиатура спецсимволов, переключатель шрифта (стандартный / Monomakh / Ponomar).
- Ссылка с запросом: `…/#q=богъ` (и `&d=ru-cu` для обратного направления).

## Запуск

```bash
npm install
npm run dev
```

Другие команды: `npm run build` (сборка в `dist/`), `npm run preview`, `npm test` (тесты ядра на `node --test`).

## Публикация на GitHub Pages

1. Отправьте проект в ветку `main` репозитория на GitHub.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` на каждый push запускает тесты, собирает проект и публикует `dist/`.

В `vite.config.js` стоит `base: './'`, поэтому сайт работает и на `user.github.io/repo/`, и на своём домене.

## Словарь

Формат статьи в `public/data/dictionary.json`:

```json
{
  "id": "богъ", "headword": "богъ", "pos": "сущ. м.", "ru": ["бог", "божество"],
  "forms": ["боже", "бога"], "titlo": ["бг҃ъ", "бг҃а"], "greek": "θεός",
  "grammar": "…", "gloss": "…", "etymology": "…", "related": ["богородица"],
  "examples": [{ "cu": "…", "ru": "…", "source": "…" }], "note": "…"
}
```

Обязательны `headword`, `pos`, `ru`. Слова из `related` должны существовать в словаре (проверяет тест). Если у статьи нет `ru`, но есть `en` (так бывает при импорте из английского Викисловаря), показывается английское толкование.

Стартовый словарь составлен вручную как учебная выборка базовой и архаичной лексики. Перед серьёзным использованием сверяйте формы и значения с научными словарями.

### Расширение базы из Викисловаря

```bash
# JSONL-дамп Kaikki (записи с lang_code "cu")
python scripts/import_wiktionary.py kaikki-cu.jsonl --merge

# или таблица TSV: headword, pos, ru, forms, greek, etymology, note
python scripts/import_wiktionary.py words.tsv --format tsv --merge
```

`--merge` добавляет только новые слова и не меняет написанные вручную статьи; формы-ссылки («род. п. ед. ч. от …») присоединяются к своей лемме. Дамп английского Викисловаря даёт только английские толкования, поэтому такие статьи не участвуют в поиске «русский → старославянский», пока в них нет `ru` (для русских толкований используйте дамп русского Викисловаря или TSV). Скрипт проверен на небольшом образце (`tests/fixtures/sample_kaikki.jsonl`), но не на полном дампе.

Текст Викисловаря распространяется по лицензии CC BY-SA 4.0: при публикации расширенной базы указывайте источник.

## Шрифты

Monomakh подключается из Google Fonts. Ponomar Unicode на Google Fonts нет: он используется, если установлен в системе (иначе подставится Monomakh). Чтобы подключить его с сайта, положите файл шрифта в `public/fonts/` и добавьте `@font-face` в `src/style.css`.
